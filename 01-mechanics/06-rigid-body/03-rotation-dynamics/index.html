Основное уравнение динамики вращения

10 класс11 класс

Перед уроком полезно знать: Момент инерции. Энергия вращения, Момент силы. Правило моментов. Рычаг, Движение связанных тел

Зачем это нужно

В статике сумма моментов была равна нулю, и тело не поворачивалось. Что будет, если она не равна нулю? Тело начнёт вращаться с ускорением — так же, как нескомпенсированная сила разгоняет тело в поступательном движении. Это нужно, чтобы рассчитать разгон двигателя, торможение колеса, движение грузов на блоке, у которого есть масса.

Главная идея: момент силы разгоняет вращение

Возьмём материальную точку массой mmm на лёгком стержне длиной rrr. Касательная сила FFF сообщает ей касательное ускорение: F=maτ=mεrF = ma_\tau = m\varepsilon rF=maτ​=mεr. Умножим на rrr: Fr=mr2εFr = mr^2\varepsilonFr=mr2ε, то есть M=IεM = I\varepsilonM=Iε. Для твёрдого тела сложим такие равенства для всех частиц — внутренние силы попарно дают нулевой суммарный момент:

Iε=∑Mвнеш.I\varepsilon = \sum M_{\text{внеш}}.Iε=∑Mвнеш​.

Это основное уравнение динамики вращения вокруг неподвижной оси — второй закон Ньютона для вращения.

Блок, у которого есть масса

В главе «Динамика» блоки были невесомыми, и натяжение нити по обе стороны было одинаковым. Если у блока есть момент инерции, натяжения разные: их разность раскручивает блок.

(T1−T2)R=Iε,a=εR (нить не проскальзывает).(T_1 - T_2)R = I\varepsilon, \qquad a = \varepsilon R \ (\text{нить не проскальзывает}).(T1​−T2​)R=Iε,a=εR (нить не проскальзывает).

План решения: для каждого груза — второй закон Ньютона, для блока — уравнение вращения, плюс связь a=εRa = \varepsilon Ra=εR. Получается система. Для груза массой mmm на нити, намотанной на сплошной диск массой MMM:

a=mgm+I/R2=mgm+M/2.a = \frac{mg}{m + I/R^2} = \frac{mg}{m + M/2}.a=m+I/R2mg​=m+M/2mg​.

Блок ведёт себя так, как будто к массе груза добавили «эффективную массу» IR2\dfrac{I}{R^2}R2I​.

Типичные ошибки

  • Натяжения по обе стороны массивного блока равны. Только для невесомого блока или при равномерном вращении.
  • В уравнение вращения подставляют силу, а не момент. Iε=MI\varepsilon = MIε=M, где M=FdM = FdM=Fd; силы, проходящие через ось (реакция оси, вес блока), момента не создают.
  • Забывают связь a=εRa = \varepsilon Ra=εR. Без неё неизвестных больше, чем уравнений.

Пример 1. Груз на массивном блоке

Условие. На сплошной цилиндрический блок массой 4 кг и радиусом 0,2 м намотана нить, к концу которой привязан груз массой 2 кг. Блок может вращаться вокруг неподвижной горизонтальной оси без трения. Груз отпускают. Найди ускорение груза, натяжение нити и угловое ускорение блока.

Дано: m=2m = 2m=2 кг, M=4M = 4M=4 кг, R=0,2R = 0{,}2R=0,2 м. Найти: aaa, TTT, ε\varepsilonε.

Анализ. Груз движется поступательно: на него действуют сила тяжести и натяжение нити. Блок вращается: момент относительно оси создаёт только натяжение нити (сила тяжести блока и реакция оси проходят через ось). Нить не проскальзывает, поэтому ускорение груза равно касательному ускорению обода: a=εRa = \varepsilon Ra=εR.

Решение.

  1. Груз: ma=mg−Tma = mg - Tma=mg−T.
  2. Блок: Iε=TRI\varepsilon = TRIε=TR, где I=MR22I = \dfrac{MR^2}{2}I=2MR2​ и ε=aR\varepsilon = \dfrac aRε=Ra​. Отсюда T=Ma2T = \dfrac{Ma}{2}T=2Ma​.
  3. Складываем: ma=mg−Ma2ma = mg - \dfrac{Ma}{2}ma=mg−2Ma​, a=mgm+M/2=204=5a = \dfrac{mg}{m + M/2} = \dfrac{20}{4} = 5a=m+M/2mg​=420​=5 м/с².
  4. T=4⋅52=10T = \dfrac{4\cdot 5}{2} = 10T=24⋅5​=10 Н, ε=50,2=25\varepsilon = \dfrac{5}{0{,}2} = 25ε=0,25​=25 рад/с².

Проверка. Предельные случаи: лёгкий блок (M→0M \to 0M→0) — груз падает свободно, a=ga = ga=g, T=0T = 0T=0; очень тяжёлый блок — a→0a \to 0a→0, T→mgT \to mgT→mg. Ответ лежит между: a=g/2a = g/2a=g/2. Радиус блока в ускорение не вошёл.

Ответ: 5 м/с²; 10 Н; 25 рад/с².

Что запомнить. Сплошной блок добавляет к массе груза «эффективную массу» M2\dfrac{M}{2}2M​: a=mgm+M/2a = \dfrac{mg}{m + M/2}a=m+M/2mg​.

Пример 2. Машина Атвуда с массивным блоком

Условие. Через блок — сплошной диск массой 2 кг — перекинута нить с грузами 3 кг и 1 кг. Нить по блоку не проскальзывает, трения в оси нет. Найди ускорение грузов и натяжения нити по обе стороны блока.

Дано: m1=3m_1 = 3m1​=3 кг, m2=1m_2 = 1m2​=1 кг, M=2M = 2M=2 кг. Найти: aaa, T1T_1T1​, T2T_2T2​.

Анализ. Тяжёлый груз опускается, лёгкий поднимается с тем же ускорением. Блок раскручивается разностью натяжений, поэтому натяжения разные. Три тела — три уравнения, плюс связь a=εRa = \varepsilon Ra=εR.

Решение.

  1. Тяжёлый груз: m1a=m1g−T1m_1a = m_1g - T_1m1​a=m1​g−T1​. Лёгкий: m2a=T2−m2gm_2a = T_2 - m_2gm2​a=T2​−m2​g.
  2. Блок: (T1−T2)R=MR22⋅aR(T_1 - T_2)R = \dfrac{MR^2}{2}\cdot\dfrac aR(T1​−T2​)R=2MR2​⋅Ra​, то есть T1−T2=Ma2T_1 - T_2 = \dfrac{Ma}{2}T1​−T2​=2Ma​.
  3. Сложим все три: (m1+m2+M/2)a=(m1−m2)g(m_1 + m_2 + M/2)a = (m_1 - m_2)g(m1​+m2​+M/2)a=(m1​−m2​)g, a=205=4a = \dfrac{20}{5} = 4a=520​=4 м/с².
  4. T1=3(10−4)=18T_1 = 3(10 - 4) = 18T1​=3(10−4)=18 Н, T2=1(10+4)=14T_2 = 1(10 + 4) = 14T2​=1(10+4)=14 Н.

Проверка. T1−T2=4T_1 - T_2 = 4T1​−T2​=4 Н =2⋅42= \dfrac{2\cdot 4}{2}=22⋅4​ — уравнение блока выполнено. С невесомым блоком было бы a=5a = 5a=5 м/с² и одинаковые натяжения по 15 Н.

Ответ: 4 м/с²; 18 Н и 14 Н.

Что запомнить. Для системы с массивным блоком: движущая сила — разность весов, инертность — сумма масс плюс IR2\dfrac{I}{R^2}R2I​.

Пример 3. Торможение маховика колодкой

Условие. Маховик с моментом инерции 2 кг·м² вращается с угловой скоростью 50 рад/с. К его ободу радиусом 0,25 м прижимают тормозную колодку с силой 100 Н, коэффициент трения 0,4. Через какое время маховик остановится? Сколько оборотов он сделает? Сколько теплоты выделится?

Дано: I=2I = 2I=2 кг·м², ω0=50\omega_0 = 50ω0​=50 рад/с, R=0,25R = 0{,}25R=0,25 м, N=100N = 100N=100 Н, μ=0,4\mu = 0{,}4μ=0,4. Найти: ttt, nnn, QQQ.

Анализ. Сила трения колодки направлена по касательной к ободу и создаёт тормозящий момент. Он постоянен, значит, вращение равнозамедленное. Теплота равна всей начальной кинетической энергии маховика.

Решение.

  1. Сила трения F=μN=40F = \mu N = 40F=μN=40 Н, тормозящий момент M=FR=10M = FR = 10M=FR=10 Н·м.
  2. ε=MI=5\varepsilon = \dfrac MI = 5ε=IM​=5 рад/с², t=ω0ε=10t = \dfrac{\omega_0}{\varepsilon} = 10t=εω0​​=10 с.
  3. Угол: φ=ω0t2=250\varphi = \dfrac{\omega_0t}{2} = 250φ=2ω0​t​=250 рад, n=2502π≈39,8n = \dfrac{250}{2\pi} \approx 39{,}8n=2π250​≈39,8 оборота.
  4. Q=Iω022=2⋅25002=2500Q = \dfrac{I\omega_0^2}{2} = \dfrac{2\cdot 2500}{2} = 2500Q=2Iω02​​=22⋅2500​=2500 Дж.

Проверка. Работа тормозящего момента Mφ=10⋅250=2500M\varphi = 10\cdot 250 = 2500Mφ=10⋅250=2500 Дж — совпадает с потерей энергии. Это аналог Fs=ΔEкFs = \Delta E_кFs=ΔEк​.

Ответ: 10 с; ≈ 40 оборотов; 2,5 кДж.

Что запомнить. Работа момента A=MφA = M\varphiA=Mφ, теорема о кинетической энергии работает и для вращения.
