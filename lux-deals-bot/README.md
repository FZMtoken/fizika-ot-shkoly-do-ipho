# Lux Deals Bot ✈️

Telegram-бот, который ищет **реально дешёвый бизнес- и первый класс** — то, что обычные
агрегаторы не показывают или показывают плохо.

## Что умеет (MVP)

| Функция | Как работает |
|---|---|
| **Слежение за ценой** | Регулярно проверяет маршрут на выбранных датах и пишет, когда цена ниже вашего лимита или на 30%+ ниже обычной для маршрута (распродажи, ошибочные тарифы). |
| **Позиционные перелёты** | Сравнивает «бизнес из дома» с вариантом «эконом до хаба накануне + бизнес из хаба» (Стамбул, Каир, Коломбо, Осло, Стокгольм, Амстердам, Мадрид, Доха). Экономия часто 20–50%. |
| **Места за мили** | Через seats.aero ищет бизнес/первый за мили (по умолчанию до 90 тыс. / 130 тыс. миль). Это самый большой источник экономии в премиум-классе. |
| **Частные джеты (empty legs)** | Перегоночные рейсы, когда джет летит пустым к следующему клиенту. Продаются со скидкой 50–75% от обычного чартера. Подписка: аэропорты вылета, куда (или «куда угодно»), даты, число пассажиров, лимит за весь борт. |
| **Разовый поиск** | `/search IST DXB 2026-11-15 [first]` |

Команды бота: `/watch`, `/jet`, `/list`, `/check`, `/search`, `/cancel`, `/help`.

## Быстрый старт

```bash
cd lux-deals-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите TELEGRAM_BOT_TOKEN
python -m bot
```

Без `DUFFEL_TOKEN` бот работает в **демо-режиме** на вымышленных ценах, так что
интерфейс можно проверить сразу.

Через Docker:

```bash
docker build -t lux-deals-bot .
docker run -d --env-file .env -v $(pwd)/data:/app/data lux-deals-bot
```

### Ключи

1. **Telegram**: напишите [@BotFather](https://t.me/BotFather), выполните `/newbot` и получите токен.
2. **Duffel** (живые цены от авиакомпаний, ~300 перевозчиков, NDC): зарегистрируйтесь на
   [duffel.com](https://duffel.com) и создайте access token. Тестовый токен (`duffel_test_…`)
   отдаёт тестовые данные, боевой — реальные цены. Проверьте актуальные тарифы Duffel на поиск.
3. **seats.aero** (места за мили): подписка Pro, ключ на [seats.aero/apikey](https://seats.aero/apikey).
   Без ключа поиск за мили просто отключён.

4. **Empty legs** (`EMPTY_LEGS_FEED`): открытого API у этого рынка нет. Профессиональная база
   Avinode доступна только брокерам и операторам. Бот читает простой JSON-фид по URL или
   из файла, формат описан в `bot/providers/empty_legs.py`. Фид может отдавать партнёр-брокер
   или оператор, ваш собственный сборщик данных (с разрешения источников) или админка.
   Без фида раздел работает на демо-данных.

Остальные настройки описаны в `.env.example`.

## Устройство

```
bot/
  __main__.py      запуск: Telegram-поллинг + фоновый мониторинг
  handlers.py      команды и диалог создания подписки
  monitor.py       проверка подписок: цены → позиционные перелёты → мили
  deals.py         чистая логика «сделка или нет» (без I/O)
  db.py            SQLite: подписки, история цен, антиспам уведомлений
  providers/       Duffel, seats.aero, фид empty legs и демо-провайдеры
  formatting.py    тексты сообщений
  parsing.py       разбор ввода пользователя
```

«Обычная цена» маршрута — это медиана наблюдений за 60 дней. Сигнал «ниже обычной»
появляется после 5+ проверок маршрута, поэтому в первые дни работает только ваш лимит.

## План развития

**Этап 2. Больше источников для авиабилетов**
- Ошибочные тарифы: мониторинг сообществ и каналов (Secret Flying, FlyerTalk), фильтр по бизнес-классу.
- Сравнение точек продаж: одна и та же цена в разных валютах и странах.
- Партнёрские ссылки (Travelpayouts, Kiwi и т.п.) вместо ссылок на Google Flights — это доход.
- Апгрейды за ставку (bid upgrade) у авиакомпаний, которые это поддерживают.

**Этап 2б. Частная авиация**
- Партнёрство с 2–3 брокерами или операторами, которые отдают фид empty legs (и платят комиссию).
- Запрос чартера «под себя»: бот собирает маршрут, даты и число пассажиров и отправляет
  заявку брокерам, они присылают предложения.
- Места в джете по отдельности (shared charter), если партнёр это поддерживает.

**Этап 3. Горящие туры, чартеры и отели 5\***
- Отели 5\* по ценам ниже обычных: API Booking/Expedia (партнёрские программы), Hotelbeds.
- Горящие туры: партнёрские API туроператоров (через Travelpayouts, отдельно по странам).
- Туристические чартеры: почти всегда эконом, поэтому только вместе с турами, где есть
  премиальные пакеты.

**Этап 4. Люкс-товары (только оригинал)**
- Распродажи официальных магазинов брендов и проверенных ритейлеров (Mytheresa, SSENSE, Net-a-Porter и др.) через партнёрские сети с товарными фидами (Rakuten, CJ, Awin).
- Ресейл только с аутентификацией (Vestiaire Collective, The RealReal) и фильтр по бренду и размеру.
- Никаких маркетплейсов без проверки подлинности.

**Монетизация**: партнёрские комиссии + платная подписка (больше маршрутов, частые проверки,
ранние уведомления об ошибочных тарифах).
