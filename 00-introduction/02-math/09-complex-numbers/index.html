Комплексные числа

11 класс

Перед уроком полезно знать: Тригонометрия, Векторы, Простейшие дифференциальные уравнения

Зачем это нужно

Колебания, волны, переменный ток — везде синусы и косинусы, и складывать их с разными фазами утомительно. Комплексные числа превращают эту тригонометрию в простую алгебру: колебание становится вектором, вращающимся на плоскости, сложение колебаний — сложением векторов, производная — поворотом на 90°. Физики пользуются ими постоянно: в теории колебаний, оптике, электротехнике и квантовой механике.

Главная идея

Введём число iii, квадрат которого равен −1-1−1: i2=−1i^2 = -1i2=−1. Комплексное число — это z=a+biz = a + biz=a+bi, где a=Re⁡za = \operatorname{Re} za=Rez — действительная часть, b=Im⁡zb = \operatorname{Im} zb=Imz — мнимая часть.

Складывают и умножают его как обычный многочлен, заменяя i2i^2i2 на −1-1−1:

(2+3i)(1−i)=2−2i+3i−3i2=5+i.(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 5 + i.(2+3i)(1−i)=2−2i+3i−3i2=5+i.

Комплексная плоскость

Число a+bia + bia+bi изображают точкой (a; b)(a;\ b)(a; b) или вектором из начала координат. Тогда

  • модуль ∣z∣=a2+b2|z| = \sqrt{a^2 + b^2}∣z∣=a2+b2​ — длина вектора;
  • аргумент φ\varphiφ — угол вектора с осью действительных чисел: tg⁡φ=b/a\operatorname{tg}\varphi = b/atgφ=b/a;
  • z=∣z∣(cos⁡φ+isin⁡φ)z = |z|(\cos\varphi + i\sin\varphi)z=∣z∣(cosφ+isinφ) — тригонометрическая форма;
  • сложение комплексных чисел — сложение векторов.

Формула Эйлера

eiφ=cos⁡φ+isin⁡φ.e^{i\varphi} = \cos\varphi + i\sin\varphi.eiφ=cosφ+isinφ.

Это единичный вектор под углом φ\varphiφ. Теперь любое комплексное число: z=∣z∣ eiφz = |z|\,e^{i\varphi}z=∣z∣eiφ.

Умножение — перемножить модули и сложить аргументы: ∣z1∣eiφ1⋅∣z2∣eiφ2=∣z1∣∣z2∣ ei(φ1+φ2)|z_1|e^{i\varphi_1}\cdot|z_2|e^{i\varphi_2} = |z_1||z_2|\,e^{i(\varphi_1 + \varphi_2)}∣z1​∣eiφ1​⋅∣z2​∣eiφ2​=∣z1​∣∣z2​∣ei(φ1​+φ2​). Умножение на eiαe^{i\alpha}eiα — поворот на угол α\alphaα. Умножение на i=eiπ/2i = e^{i\pi/2}i=eiπ/2 — поворот на 90°.

Отсюда красивые следствия: (cos⁡φ+isin⁡φ)n=cos⁡nφ+isin⁡nφ(\cos\varphi + i\sin\varphi)^n = \cos n\varphi + i\sin n\varphi(cosφ+isinφ)n=cosnφ+isinnφ (формула Муавра), и знаменитое eiπ+1=0e^{i\pi} + 1 = 0eiπ+1=0.

Колебания как вращающийся вектор

Колебание x=Acos⁡(ωt+φ0)x = A\cos(\omega t + \varphi_0)x=Acos(ωt+φ0​) — это действительная часть вектора A ei(ωt+φ0)A\,e^{i(\omega t + \varphi_0)}Aei(ωt+φ0​), который вращается с угловой скоростью ω\omegaω. Такие векторы называют фазорами.

Сложение колебаний одной частоты — это сложение векторов. Два колебания с амплитудами A1A_1A1​, A2A_2A2​ и разностью фаз Δφ\Delta\varphiΔφ дают колебание с амплитудой

A=A12+A22+2A1A2cos⁡ΔφA = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos\Delta\varphi}A=A12​+A22​+2A1​A2​cosΔφ​

— теорема косинусов для треугольника векторов. При Δφ=0\Delta\varphi = 0Δφ=0 амплитуды складываются, при Δφ=180∘\Delta\varphi = 180^\circΔφ=180∘ — вычитаются. Это основа интерференции волн.

Производная ddteiωt=iω eiωt\dfrac{d}{dt}e^{i\omega t} = i\omega\,e^{i\omega t}dtd​eiωt=iωeiωt: вектор скорости повёрнут на 90° и длиннее в ω\omegaω раз. Уравнение осциллятора x¨=−ω2x\ddot x = -\omega^2 xx¨=−ω2x решается подстановкой x=eλtx = e^{\lambda t}x=eλt: λ2=−ω2\lambda^2 = -\omega^2λ2=−ω2, λ=±iω\lambda = \pm i\omegaλ=±iω.

Для олимпиадников: затухание и импеданс

  • Затухающие колебания x¨+2γx˙+ω02x=0\ddot x + 2\gamma\dot x + \omega_0^2 x = 0x¨+2γx˙+ω02​x=0: λ=−γ±iω02−γ2\lambda = -\gamma \pm i\sqrt{\omega_0^2 - \gamma^2}λ=−γ±iω02​−γ2​. Действительная часть λ\lambdaλ даёт затухание e−γte^{-\gamma t}e−γt, мнимая — частоту колебаний.
  • Цепи переменного тока. У каждого элемента есть комплексное сопротивление — импеданс: ZR=RZ_R = RZR​=R, ZL=iωLZ_L = i\omega LZL​=iωL, ZC=1iωCZ_C = \dfrac{1}{i\omega C}ZC​=iωC1​. Цепи считают по законам Ома, как для постоянного тока, но с комплексными числами.

Типичные ошибки

  • i2=1i^2 = 1i2=1. Нет, i2=−1i^2 = -1i2=−1, i3=−ii^3 = -ii3=−i, i4=1i^4 = 1i4=1.
  • Аргумент через арктангенс без учёта четверти. У −1−i-1 - i−1−i аргумент 225∘225^\circ225∘, а не 45∘45^\circ45∘.
  • Модуль суммы — сумма модулей. Как и для векторов, это неверно.
  • Физическая величина комплексная. Координата, ток, напряжение — это действительные части комплексных выражений.

Пример 1. Степень без раскрытия скобок

Условие. Вычисли (1+i)8(1 + i)^8(1+i)8.

Дано: z=1+iz = 1 + iz=1+i. Найти: z8z^8z8.

Анализ. Раскрывать скобки восемь раз долго. В показательной форме z=reiφz = r e^{i\varphi}z=reiφ возведение в степень делается сразу: модуль возводится в степень, аргумент умножается на показатель. Найдём модуль и аргумент числа 1+i1 + i1+i.

Решение.

  1. Модуль: ∣1+i∣=12+12=2|1 + i| = \sqrt{1^2 + 1^2} = \sqrt 2∣1+i∣=12+12​=2​.
  2. Аргумент: точка (1;1)(1; 1)(1;1) лежит на биссектрисе первой четверти, φ=π4\varphi = \dfrac{\pi}{4}φ=4π​.
  3. 1+i=2 eiπ/41 + i = \sqrt 2\,e^{i\pi/4}1+i=2​eiπ/4.
  4. (1+i)8=(2)8 ei⋅8π/4=16 e2πi=16(1 + i)^8 = (\sqrt 2)^8\,e^{i\cdot 8\pi/4} = 16\,e^{2\pi i} = 16(1+i)8=(2​)8ei⋅8π/4=16e2πi=16.

Проверка. Короткий путь: (1+i)2=1+2i+i2=2i(1 + i)^2 = 1 + 2i + i^2 = 2i(1+i)2=1+2i+i2=2i. Тогда (1+i)8=(2i)4=16i4=16(1 + i)^8 = (2i)^4 = 16i^4 = 16(1+i)8=(2i)4=16i4=16 — совпадает.

Ответ: 16.

Что запомнить. Умножение комплексных чисел — это умножение модулей и сложение углов. Для степеней переходи к показательной форме.

Пример 2. Сумма синуса и косинуса

Условие. Представь x=3cos⁡ωt+4sin⁡ωtx = 3\cos\omega t + 4\sin\omega tx=3cosωt+4sinωt в виде Acos⁡(ωt−φ)A\cos(\omega t - \varphi)Acos(ωt−φ). Найди AAA и φ\varphiφ.

Дано: x=3cos⁡ωt+4sin⁡ωtx = 3\cos\omega t + 4\sin\omega tx=3cosωt+4sinωt. Найти: AAA, φ\varphiφ.

Анализ. Каждое колебание Akcos⁡(ωt−φk)A_k\cos(\omega t - \varphi_k)Ak​cos(ωt−φk​) изображается фазором — комплексным числом Ake−iφkA_k e^{-i\varphi_k}Ak​e−iφk​. Решение.

  1. Фазор первого слагаемого: 333 (амплитуда 3, сдвиг 0).
  2. Фазор второго: амплитуда 4, сдвиг 90°90°90°, то есть 4e−i⋅90°=−4i4e^{-i\cdot 90°} = -4i4e−i⋅90°=−4i.

  5. Сдвиг: tg⁡φ=43\operatorname{tg}\varphi = \dfrac{4}{3}tgφ=34​, φ≈53,1°\varphi \approx 53{,}1°φ≈53,1°.
  6. x=5cos⁡(ωt−53,1°)x = 5\cos(\omega t - 53{,}1°)x=5cos(ωt−53,1°).

Проверка. Раскроем: 5cos⁡(ωt−φ)=5cos⁡φcos⁡ωt+5sin⁡φsin⁡ωt=5⋅0,6cos⁡ωt+5⋅0,8sin⁡ωt=3cos⁡ωt+4sin⁡ωt5\cos(\omega t - \varphi) = 5\cos\varphi\cos\omega t + 5\sin\varphi\sin\omega t = 5\cdot 0{,}6\cos\omega t + 5\cdot 0{,}8\sin\omega t = 3\cos\omega t + 4\sin\omega t5cos(ωt−φ)=5cosφcosωt+5sinφsinωt=5⋅0,6cosωt+5⋅0,8sinωt=3cosωt+4sinωt — верно.

Что запомнить. Сложение колебаний одной частоты сводится к сложению векторов-фазоров. И снова треугольник 3–4–5.

Пример 3. Цепь из резистора и конденсатора

Условие. Резистор 100 Ом и конденсатор 10 мкФ соединены последовательно и подключены к переменному напряжению с амплитудой 10 В и циклической частотой 1000 рад/с. Найди модуль импеданса, сдвиг фаз между током и напряжением и амплитуду тока.

Дано: R=100R = 100R=100 Ом, C=10−5C = 10^{-5}C=10−5 Ф, U0=10U_0 = 10U0​=10 В, ω=1000\omega = 1000ω=1000 рад/с. Найти: ∣Z∣|Z|∣Z∣, сдвиг фаз, I0I_0I0​.

Анализ. В комплексной форме каждый элемент цепи — это «сопротивление»: резистор RRR, конденсатор 1iωC\dfrac{1}{i\omega C}iωC1​. При последовательном соединении они складываются, как обычные сопротивления. Тогда закон Ома I=U/ZI = U/ZI=U/Z работает для комплексных амплитуд: модуль ZZZ даёт амплитуду тока, аргумент — сдвиг фаз.

Решение.

  1. ωC=1000⋅10−5=0,01\omega C = 1000\cdot 10^{-5} = 0{,}01ωC=1000⋅10−5=0,01 Ом⁻¹. Сопротивление конденсатора: 1i⋅0,01=100i=−100i\dfrac{1}{i\cdot 0{,}01} = \dfrac{100}{i} = -100ii⋅0,011​=i100​=−100i Ом.
  2. Импеданс цепи: Z=100−100iZ = 100 - 100iZ=100−100i Ом.
