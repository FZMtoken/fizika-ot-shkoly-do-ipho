Алгебра физика

7 класс8 класс9 класс

Зачем это нужно

Физическая задача почти всегда заканчивается алгеброй: выразить неизвестное из формулы, решить систему, найти корень квадратного уравнения, сравнить «во сколько раз». Ошибка в алгебре губит правильную физику. В этом уроке собраны приёмы, которыми физики пользуются каждый день, — и привычки, которые отличают сильного решателя.

Главная привычка: решать в общем виде

Сначала получи ответ буквами, числа подставляй в самом конце.

Почему это важно:

  • Меньше ошибок. Буквы не округляются, промежуточных вычислений меньше.
  • Можно проверить. По формуле видно, правильные ли единицы и разумно ли поведение: например, растёт ли время, если скорость уменьшается.
  • Часть величин сокращается. Очень часто неизвестная длина или масса исчезает из ответа — числа для неё и не понадобились бы.
  • Ответ работает для любых чисел. Одну формулу можно использовать в следующей задаче.

Выражаем величину из формулы

Правило одно: с обеими частями равенства можно делать одно и то же действие. Цель — оставить нужную величину одну.

Пример. Из s=at22s = \dfrac{a t^2}{2}s=2at2​ выразим ttt:

2s=at2  ⇒  t2=2sa  ⇒  t=2sa.2s = a t^2 \;\Rightarrow\; t^2 = \frac{2s}{a} \;\Rightarrow\; t = \sqrt{\frac{2s}{a}}.2s=at2⇒t2=a2s​⇒t=a2s​​.

Пример. Из v2−v02=2asv^2 - v_0^2 = 2asv2−v02​=2as выразим v0v_0v0​:   v0=v2−2as\;v_0 = \sqrt{v^2 - 2as}v0​=v2−2as​.

Проверяй результат размерностью: под корнем в первом примере мм/с2=с2\dfrac{\text{м}}{\text{м/с}^2} = \text{с}^2м/с2м​=с2, корень даёт секунды — верно.

Пропорции и «во сколько раз»

Если y=Cxny = C x^ny=Cxn, то при изменении xxx в kkk раз величина yyy меняется в knk^nkn раз. Формула может быть громоздкой, но для ответа «во сколько раз» нужны только степени.

Пример. Сила тяготения F=Gm1m2r2F = G\dfrac{m_1 m_2}{r^2}F=Gr2m1​m2​​. Массы увеличили в 2 и в 3 раза, расстояние — в 2 раза. Сила изменится в 2⋅322=1,5\dfrac{2\cdot 3}{2^2} = 1{,}5222⋅3​=1,5 раза.

Относительное изменение. Если величина выросла с AAA до BBB, то на B−AA⋅100%\dfrac{B - A}{A}\cdot 100\%AB−A​⋅100%.

Стандартный вид чисел

Физика работает с числами от размеров атома до расстояний между галактиками. Их записывают как a⋅10na\cdot 10^na⋅10n, где 1≤a<101 \le a < 101≤a<10:

3 200 000=3,2⋅106,0,00056=5,6⋅10−4.3\,200\,000 = 3{,}2\cdot 10^6, \qquad 0{,}00056 = 5{,}6\cdot 10^{-4}.3200000=3,2⋅106,0,00056=5,6⋅10−4.

Правила: 10m⋅10n=10m+n10^m\cdot 10^n = 10^{m+n}10m⋅10n=10m+n,   10m10n=10m−n\;\dfrac{10^m}{10^n} = 10^{m-n}10n10m​=10m−n,   (10m)n=10mn\;(10^m)^n = 10^{mn}(10m)n=10mn.

Системы уравнений

Если неизвестных две, нужны два уравнения. Два основных способа:

  • Подстановка: выразить одну неизвестную из первого уравнения и подставить во второе.
  • Сложение и вычитание: сложить или вычесть уравнения так, чтобы одна неизвестная исчезла.

Пример. Лодка по течению идёт со скоростью 5 м/с, против течения — 3 м/с. Найти скорость лодки vvv и течения uuu:

v+u=5,v−u=3  ⇒  2v=8,  v=4 м/с,  u=1 м/с.v + u = 5, \quad v - u = 3 \;\Rightarrow\; 2v = 8,\; v = 4\ \text{м/с},\; u = 1\ \text{м/с}.v+u=5,v−u=3⇒2v=8,v=4 м/с,u=1 м/с.

Графически решение системы двух линейных уравнений — точка пересечения двух прямых. Прямые могут пересекаться в одной точке, быть параллельными (решений нет) или совпадать (решений бесконечно много).

Квадратные уравнения

ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 решается по формуле x1,2=−b±b2−4ac2ax_{1,2} = \dfrac{-b \pm\sqrt{b^2 - 4ac}}{2a}x1,2​=2a−b±b2−4ac​​. В физике у корней есть смысл: у брошенного вверх мяча два момента, когда он на одной высоте, — при подъёме и при спуске. Иногда один из корней не подходит по смыслу: отрицательное время, отрицательная длина. Подробнее — в подтеме «Функции и графики».

Малые погрешности

Если величина xxx известна с относительной погрешностью ε\varepsilonε, то у xnx^nxn относительная погрешность примерно nεn\varepsilonnε. Радиус измерен с погрешностью 1% — площадь круга известна с погрешностью 2%, объём шара — 3%.

Типичные ошибки

  • Числа с самого начала. Длинная цепочка округлений даёт неверный ответ, и его невозможно проверить.
  • Потерянный корень. Из t2=9t^2 = 9t2=9 следует t=±3t = \pm 3t=±3; отбрасывать корень можно только по физическому смыслу.
  • Ошибка в степени при «во сколько раз». В F∝1/r2F \propto 1/r^2F∝1/r2 увеличение rrr в 3 раза уменьшает силу в 9 раз, а не в 3.
  • Проценты от разных величин. Рост на 20%, а потом падение на 20% не возвращают к исходному: 1,2⋅0,8=0,961{,}2\cdot 0{,}8 = 0{,}961,2⋅0,8=0,96.

Разобранные задачи

Типовые задачи темы с полным ходом решения. Разбери их, прежде чем переходить к задачам для самостоятельного решения.

A

Пример 1. Сколько длился разгон

Условие. Путь при разгоне из покоя s=at22s = \dfrac{at^2}{2}s=2at2​. Вырази из этой формулы время ttt и найди его при s=100s = 100s=100 м, a=2a = 2a=2 м/с².

Дано: s=at22s = \dfrac{at^2}{2}s=2at2​, s=100s = 100s=100 м, a=2a = 2a=2 м/с². Найти: формулу для ttt и его значение.

Анализ. Сначала выражаем ttt в общем виде, и только потом подставляем числа. Неизвестная ttt стоит в квадрате, поэтому последним действием будет извлечение корня.

Решение.

  1. Умножаем обе части на 2: 2s=at22s = at^22s=at2.
  2. Делим обе части на aaa: t2=2sat^2 = \dfrac{2s}{a}t2=a2s​.
  3. Извлекаем корень (время положительно): t=2sat = \sqrt{\dfrac{2s}{a}}t=a2s​​.
  4. Подставляем: t=2⋅1002=100=10t = \sqrt{\dfrac{2\cdot 100}{2}} = \sqrt{100} = 10t=22⋅100​​=100​=10 с.

Проверка. Размерность: мм/с2=с2=с\sqrt{\dfrac{\text{м}}{\text{м/с}^2}} = \sqrt{\text{с}^2} = \text{с}м/с2м​​=с2​=с — время. Обратная подстановка: 2⋅1022=100\dfrac{2\cdot 10^2}{2} = 10022⋅102​=100 м — совпадает с условием.

Ответ: t=2s/at = \sqrt{2s/a}t=2s/a​; 10 с.

Что запомнить. Порядок действий: выразить в общем виде → проверить размерность → подставить числа. Проверка размерности занимает одну строку и ловит большинство ошибок.

Пример 2. Во сколько раз изменится сила

Условие. Сила притяжения F=Gm1m2r2F = G\dfrac{m_1 m_2}{r^2}F=Gr2m1​m2​​. Массу первого тела увеличили в 2 раза, второго — в 3 раза, а расстояние между ними — в 2 раза. Во сколько раз изменилась сила?

Дано: m1′=2m1m_1' = 2m_1m1′​=2m1​, m2′=3m2m_2' = 3m_2m2′​=3m2​, r′=2rr' = 2rr′=2r. Найти: F′/FF'/FF′/F.

Анализ. Нам не нужны сами значения масс и расстояния — только то, во сколько раз они изменились. Запишем отношение новой силы к старой: всё неизменное (GGG, исходные m1m_1m1​, m2m_2m2​, rrr) сократится.

Решение.

  1. Новая сила: F′=G(2m1)(3m2)(2r)2=G6m1m24r2F' = G\dfrac{(2m_1)(3m_2)}{(2r)^2} = G\dfrac{6m_1 m_2}{4r^2}F′=G(2r)2(2m1​)(3m2​)​=G4r26m1​m2​​.
  2. Отношение: F′F=64=1,5\dfrac{F'}{F} = \dfrac{6}{4} = 1{,}5FF′​=46​=1,5.

Проверка. По отдельности: массы дают множитель 2⋅3=62\cdot 3 = 62⋅3=6, расстояние в квадрате в знаменателе даёт 14\dfrac{1}{4}41​. Итог 6/4=1,5>16/4 = 1{,}5 > 16/4=1,5>1 — сила выросла, потому что массы выросли сильнее, чем квадрат расстояния.

Ответ: увеличилась в 1,5 раза.

Что запомнить. В задачах «во сколько раз» пиши отношение новой величины к старой. Каждый множитель входит в ответ в своей степени.

Условие. Автомобиль проехал первую половину пути со скоростью v1v_1v1​, вторую — со скоростью v2v_2v2​. Выведи формулу средней скорости. Какой должна быть v2v_2v2​, чтобы при v1=60v_1 = 60v1​=60 км/ч средняя скорость оказалась 48 км/ч?

vср=2ss/v1+s/v2=21/v1+1/v2=2v1v2v1+v2.v_{\text{ср}} = \frac{2s}{s/v_1 + s/v_2} = \frac{2}{1/v_1 + 1/v_2} = \frac{2v_1 v_2}{v_1 + v_2}.vср​=s/v1​+s/v2​2s​=1/v1​+1/v2​2​=v1​+v2​2v1​v2​​.
