Приближения

Чёрная линия — точная функция, синяя — приближение первого порядка, зелёная — второго. Вблизи нуля они почти совпадают.

Попробуй сам:
  1. Выбери (1 + x)ⁿ с n = 0,5. До какого x ошибка первого порядка меньше 1%?
  2. Для cos x сравни приближения первого и второго порядка. Почему первое бесполезно?
  3. Для sin x найди угол в градусах, при котором ошибка приближения sin x ≈ x достигает 1%.
