Плавление и кристаллизация

8 класс9 класс10 класс черновик: ждёт проверки автора

Перед уроком полезно знать: Внутренняя энергия и теплота. Теплоёмкость. Уравнение теплового баланса

Зачем это нужно

Почему лёд в стакане тает, а температура воды остаётся около нуля, пока не растает последний кубик? Почему зимой лопаются трубы с водой? Почему весной снег тает неделями, хотя солнце светит ярко? Ответ один: чтобы расплавить кристалл, нужно много энергии — и всё это время температура не меняется. Здесь мы научимся учитывать плавление и кристаллизацию в уравнении теплового баланса.

Агрегатные состояния и фазовые переходы

Вещество бывает твёрдым, жидким и газообразным. Переход из одного состояния в другое называют фазовым переходом:

Переход Название Теплота
твёрдое → жидкое плавление поглощается
жидкое → твёрдое кристаллизация (отвердевание) выделяется
жидкое → газ испарение, кипение поглощается
газ → жидкое конденсация выделяется
твёрдое → газ сублимация (возгонка) поглощается

В кристалле молекулы стоят в узлах решётки и связаны друг с другом. Чтобы разрушить решётку, нужно совершить работу против сил притяжения — на это и идёт теплота плавления. Средняя кинетическая энергия молекул (а значит, и температура) при этом не растёт.

Удельная теплота плавления

Кристаллическое вещество плавится при определённой температуре плавления tплt_{\text{пл}}tпл​. Пока идёт плавление, температура не меняется. Теплота, нужная для плавления массы mmm, уже нагретой до tплt_{\text{пл}}tпл​:

Q=λm.Q = \lambda m.Q=λm.

λ\lambdaλ — удельная теплота плавления, Дж/кг. При кристаллизации выделяется столько же теплоты.

Вещество tплt_{\text{пл}}tпл​, °C λ\lambdaλ, кДж/кг
лёд 0 330
олово 232 59
свинец 327 25
алюминий 660 390
медь 1085 210
железо 1538 270

У льда теплота плавления очень большая: чтобы растопить 1 кг льда, нужно столько же энергии, сколько на нагрев 1 кг воды на 79 °C.

График нагревания

Если равномерно нагревать лёд, взятый при −20 °C, температура меняется так:

  1. лёд нагревается до 0 °C — наклонный участок (Q=cлmΔtQ = c_{\text{л}}m\Delta tQ=cл​mΔt);
  2. лёд плавится при 0 °C — горизонтальный участок (Q=λmQ = \lambda mQ=λm);
  3. вода нагревается до 100 °C — наклонный участок, более пологий: у воды теплоёмкость вдвое больше, чем у льда;
  4. вода кипит при 100 °C — снова горизонтальный участок (Испарение и кипение).

Аморфные тела (стекло, пластик, воск) не имеют определённой температуры плавления: они постепенно размягчаются, и горизонтального участка у них нет.

Особенности воды

Большинство веществ при плавлении расширяются. Вода — исключение: при замерзании её объём растёт примерно на 10 %, и лёд легче воды (плотность около 900 кг/м³ против 1000). Поэтому лёд плавает, водоёмы замерзают сверху, а вода, замерзая в трубах и трещинах камней, разрывает их.

Чистую воду можно охладить ниже 0 °C, не заморозив, — получится переохлаждённая вода. Стоит её встряхнуть или бросить кристаллик — она мгновенно частично замерзает, а температура поднимается до 0 °C.

Как решать задачи

  1. Выпиши все процессы для каждого тела: нагрев, плавление, нагрев жидкости — каждый со своей формулой.
  2. Проверь, растает ли весь лёд. Сравни теплоту, нужную для полного плавления, с теплотой, которую отдадут тёплые тела, остыв до 0 °C.
  3. Если теплоты не хватает — в конце смесь льда и воды при 0 °C; найди, сколько льда растаяло.
  4. Если хватает — составь уравнение баланса с неизвестной конечной температурой выше 0 °C.

Типичные ошибки

  • При плавлении температура растёт. У кристаллов — нет, вся теплота идёт на разрушение решётки.
  • Лёд при 0 °C сразу считают водой. Его сначала нужно растопить: λm\lambda mλm.
  • Не проверяют, растает ли весь лёд. Если теплоты не хватает, уравнение даст конечную температуру ниже нуля — это признак ошибки.
  • Путают теплоёмкости льда и воды. У льда 2100 Дж/(кг·°C), у воды 4200.

Разобранные задачи

A

Пример 1. Из льда — тёплая вода

Условие. Сколько теплоты нужно, чтобы 2 кг льда при −10 °C превратить в воду при 20 °C?

Дано: m=2m = 2m=2 кг, cл=2100c_{\text{л}} = 2100cл​=2100, cв=4200c_{\text{в}} = 4200cв​=4200 Дж/(кг·°C), λ=3,3⋅105\lambda = 3{,}3\cdot 10^5λ=3,3⋅105 Дж/кг. Найти: QQQ.

Анализ. Три процесса: нагрев льда до 0 °C, плавление, нагрев воды до 20 °C.

Решение.

  1. Нагрев льда: Q1=2100⋅2⋅10=42 000Q_1 = 2100\cdot 2\cdot 10 = 42\,000Q1​=2100⋅2⋅10=42000 Дж.
  2. Плавление: Q2=3,3⋅105⋅2=660 000Q_2 = 3{,}3\cdot 10^5\cdot 2 = 660\,000Q2​=3,3⋅105⋅2=660000 Дж.
  3. Нагрев воды: Q3=4200⋅2⋅20=168 000Q_3 = 4200\cdot 2\cdot 20 = 168\,000Q3​=4200⋅2⋅20=168000 Дж.
  4. Q=870 000Q = 870\,000Q=870000 Дж.

Проверка. Плавление забирает 3/4 всей теплоты — больше, чем оба нагрева вместе. Это типично для льда.

Ответ: 870 кДж.

Что запомнить. Разбивай процесс на участки графика нагревания: на наклонных cmΔtcm\Delta tcmΔt, на горизонтальных λm\lambda mλm.

B

Пример 2. Лёд растаял весь

Условие. В 400 г воды при 30 °C бросили 100 г льда при 0 °C. Какая установится температура?

Дано: mв=0,4m_{\text{в}} = 0{,}4mв​=0,4 кг, tв=30t_{\text{в}} = 30tв​=30 °C, mл=0,1m_{\text{л}} = 0{,}1mл​=0,1 кг. Найти: ttt.

Анализ. Сначала проверим, растает ли весь лёд: сравним теплоту плавления с теплотой, которую отдаст вода, остыв до 0 °C.

Решение.

  1. Для плавления нужно 3,3⋅105⋅0,1=33 0003{,}3\cdot 10^5\cdot 0{,}1 = 33\,0003,3⋅105⋅0,1=33000 Дж.
  2. Вода, остыв до 0 °C, отдаст 4200⋅0,4⋅30=50 4004200\cdot 0{,}4\cdot 30 = 50\,4004200⋅0,4⋅30=50400 Дж — хватает.
  3. Баланс: 4200⋅0,4⋅(30−t)=33 000+4200⋅0,1⋅t4200\cdot 0{,}4\cdot(30 - t) = 33\,000 + 4200\cdot 0{,}1\cdot t4200⋅0,4⋅(30−t)=33000+4200⋅0,1⋅t.
  4. 50 400−1680t=33 000+420t50\,400 - 1680t = 33\,000 + 420t50400−1680t=33000+420t, t=17 4002100≈8,3t = \dfrac{17\,400}{2100} \approx 8{,}3t=210017400​≈8,3 °C.

Проверка. Если бы лёд был водой при 0 °C, получилось бы 0,4⋅300,5=24\dfrac{0{,}4\cdot 30}{0{,}5} = 240,50,4⋅30​=24 °C. Лёд охлаждает намного сильнее, чем вода той же температуры.

Ответ: ≈ 8,3 °C.

Что запомнить. Талая вода тоже нагревается — от 0 °C до конечной температуры.

B

Пример 3. Лёд растаял не весь

Условие. В 300 г воды при 20 °C бросили 200 г льда при 0 °C. Что получится? Сколько льда растает?

Дано: mв=0,3m_{\text{в}} = 0{,}3mв​=0,3 кг, tв=20t_{\text{в}} = 20tв​=20 °C, mл=0,2m_{\text{л}} = 0{,}2mл​=0,2 кг. Найти: конечное состояние, Δm\Delta mΔm.

Анализ. Снова сначала проверяем, хватит ли теплоты на весь лёд.

Решение.

  1. Для плавления всего льда нужно 3,3⋅105⋅0,2=66 0003{,}3\cdot 10^5\cdot 0{,}2 = 66\,0003,3⋅105⋅0,2=66000 Дж.
  2. Вода, остыв до 0 °C, отдаст только 4200⋅0,3⋅20=25 2004200\cdot 0{,}3\cdot 20 = 25\,2004200⋅0,3⋅20=25200 Дж — не хватит.

Проверка. Если бы мы сразу составили уравнение для конечной температуры, получили бы t<0t < 0t<0 °C — при этом вода должна была бы замёрзнуть, а лёд растаять одновременно. Противоречие показывает, что надо проверять.

Ответ: смесь при 0 °C; растает ≈ 76 г, останется ≈ 124 г льда.

Что запомнить. Если теплоты не хватает на весь лёд, конечная температура ровно 0 °C.
