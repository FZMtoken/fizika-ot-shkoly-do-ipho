Тепловые двигатели и холодильники. Цикл Карно

10 класс черновик: ждёт проверки автора

Перед уроком полезно знать: Первый закон для изопроцессов. Адиабата. Теплоёмкости газа

Зачем это нужно

Около 80 % электроэнергии Казахстана дают тепловые электростанции на угле и газе. Автомобиль, самолёт, тепловоз — тоже тепловые двигатели. Холодильник и тепловой насос — те же машины, работающие в обратную сторону. Главный вопрос этой подтемы: какую часть теплоты можно превратить в работу. Ответ дал Сади Карно в 1824 году, ещё до открытия первого закона термодинамики.

Как устроен тепловой двигатель

У любого теплового двигателя три части:

  • нагреватель с температурой T1T_1T1​ — отдаёт рабочему телу теплоту Q1Q_1Q1​ (топка, камера сгорания);
  • рабочее тело — газ или пар, который совершает циклический процесс и работу AAA;
  • холодильник с температурой T2T_2T2​ — получает теплоту Q2Q_2Q2​ (атмосфера, градирня, река).

За цикл рабочее тело возвращается в исходное состояние, ΔU=0\Delta U = 0ΔU=0, поэтому A=Q1−Q2A = Q_1 - Q_2A=Q1​−Q2​. Коэффициент полезного действия

η=AQ1=1−Q2Q1.\eta = \frac{A}{Q_1} = 1 - \frac{Q_2}{Q_1}.η=Q1​A​=1−Q1​Q2​​.

Отдать часть теплоты холодильнику необходимо: двигатель, который всю полученную теплоту превращает в работу, невозможен. Это одна из формулировок второго закона термодинамики (подробнее — в подтеме «Энтропия»).

Цикл Карно

Карно предложил идеальный цикл из двух изотерм и двух адиабат:

  1. изотермическое расширение при T1T_1T1​ — газ получает Q1Q_1Q1​;
  2. адиабатное расширение — газ охлаждается от T1T_1T1​ до T2T_2T2​;
  3. изотермическое сжатие при T2T_2T2​ — газ отдаёт Q2Q_2Q2​;
  4. адиабатное сжатие — газ нагревается обратно до T1T_1T1​.

Для идеального газа Q1=νRT1ln⁡V2V1Q_1 = \nu RT_1\ln\dfrac{V_2}{V_1}Q1​=νRT1​lnV1​V2​​, Q2=νRT2ln⁡V3V4Q_2 = \nu RT_2\ln\dfrac{V_3}{V_4}Q2​=νRT2​lnV4​V3​​, а из уравнений адиабат V2V1=V3V4\dfrac{V_2}{V_1} = \dfrac{V_3}{V_4}V1​V2​​=V4​V3​​. Поэтому Q2Q1=T2T1\dfrac{Q_2}{Q_1} = \dfrac{T_2}{T_1}Q1​Q2​​=T1​T2​​ и

ηКарно=1−T2T1.\eta_{\text{Карно}} = 1 - \frac{T_2}{T_1}.ηКарно​=1−T1​T2​​.

Теорема Карно: никакой двигатель, работающий между нагревателем T1T_1T1​ и холодильником T2T_2T2​, не может иметь КПД больше 1−T2T11 - \dfrac{T_2}{T_1}1−T1​T2​​. Температуры — в кельвинах.

Чтобы поднять КПД, повышают температуру нагревателя (жаропрочные материалы) и понижают температуру холодильника.

КПД произвольного цикла

Для цикла на графике p(V)p(V)p(V):

  1. работа за цикл AAA — площадь цикла;
  2. Q1Q_1Q1​ — сумма теплот на тех участках, где газ получает теплоту (Q>0Q > 0Q>0), по первому закону для каждого участка;
  3. η=AQ1\eta = \dfrac{A}{Q_1}η=Q1​A​.

Частая ошибка — делить работу на сумму всех теплот с учётом знака: она равна работе, и получается 100 %.

Холодильник и тепловой насос

Если цикл провести в обратную сторону, внешняя работа AAA (электродвигатель компрессора) переносит теплоту Q2Q_2Q2​ от холодного тела к горячему, и горячему отдаётся Q1=Q2+AQ_1 = Q_2 + AQ1​=Q2​+A.

  • Холодильник забирает теплоту из камеры. Его качество — холодильный коэффициент ε=Q2A⩽T2T1−T2\varepsilon = \dfrac{Q_2}{A} \leqslant \dfrac{T_2}{T_1 - T_2}ε=AQ2​​⩽T1​−T2​T2​​.
  • Тепловой насос обогревает дом теплотой с улицы. Его качество — коэффициент преобразования φ=Q1A⩽T1T1−T2\varphi = \dfrac{Q_1}{A} \leqslant \dfrac{T_1}{T_1 - T_2}φ=AQ1​​⩽T1​−T2​T1​​.

Оба коэффициента могут быть больше 1: машина не производит теплоту, а переносит её. Тепловой насос даёт в 3–4 раза больше теплоты, чем электрообогреватель при той же мощности.

Как решать задачи

  1. Определи Q1Q_1Q1​, Q2Q_2Q2​ и AAA — любые два дают третье: A=Q1−Q2A = Q_1 - Q_2A=Q1​−Q2​.
  2. Для цикла найди теплоту на каждом участке и сложи только полученные.
  3. Для предельных оценок — формулы Карно с температурами в кельвинах.
  4. Проверь: реальный КПД меньше КПД Карно, холодильный коэффициент реального холодильника меньше идеального.

Типичные ошибки

  • Температуры в формуле Карно в градусах Цельсия. Только кельвины: 1−275271 - \dfrac{27}{527}1−52727​ вместо 1−3008001 - \dfrac{300}{800}1−800300​ даёт неверный ответ.
  • КПД цикла = работа / вся теплота. Делить нужно на теплоту, полученную от нагревателя.
  • Холодильный коэффициент не может быть больше 1. Может и обычно бывает: 3–6.
  • Холодильник с открытой дверцей охладит кухню. Наоборот: он отдаёт в комнату Q2+AQ_2 + AQ2​+A — больше, чем забирает.
