Зачем это нужно

На олимпиадах термодинамика — одна из самых частых тем: КПД хитрых циклов, процессы с необычной теплоёмкостью, колебания поршня, наибольшая работа. Формулы те же — первый закон, уравнение состояния, энтропия. Нужны приёмы, как их применять. Ниже — пять приёмов. Уровень подтемы — C–E.

Приём 1. Теплоёмкость процесса

Для любого процесса с идеальным газом молярная теплоёмкость

C=δQν dT=CV+p dVν dT.C = \frac{\delta Q}{\nu\,dT} = C_V + \frac{p\,dV}{\nu\,dT}.C=νdTδQ​=CV​+νdTpdV​.

Чтобы её найти, продифференцируй уравнение процесса вместе с pV=νRTpV = \nu RTpV=νRT. Например, для p=αVp = \alpha Vp=αV: pV=αV2=νRTpV = \alpha V^2 = \nu RTpV=αV2=νRT, откуда 2αV dV=νR dT2\alpha V\,dV = \nu R\,dT2αVdV=νRdT и p dV=νR dT2p\,dV = \dfrac{\nu R\,dT}{2}pdV=2νRdT​. Значит, C=CV+R2C = C_V + \dfrac R2C=CV​+2R​.

Для политропы pVn=constpV^n = \text{const}pVn=const:

C=CV−Rn−1.C = C_V - \frac{R}{n - 1}.C=CV​−n−1R​.

Частные случаи: n=0n = 0n=0 — изобара (CpC_pCp​), n=1n = 1n=1 — изотерма (C=∞C = \inftyC=∞), n=γn = \gamman=γ — адиабата (C=0C = 0C=0), n→∞n \to \inftyn→∞ — изохора (CVC_VCV​). При 1<n<γ1 < n < \gamma1<n<γ теплоёмкость отрицательна: газ получает теплоту, но остывает — работа расширения больше полученной теплоты.

Приём 2. Где газ получает теплоту

На сложном участке процесса газ может сначала получать теплоту, а потом отдавать. Чтобы найти Q1Q_1Q1​ в КПД, ищут точку смены знака: δQ=νCV dT+p dV=0\delta Q = \nu C_V\,dT + p\,dV = 0δQ=νCV​dT+pdV=0.

Для прямой p=a−bVp = a - bVp=a−bV и одноатомного газа: δQ=(52a−4bV)dV\delta Q = \left(\dfrac52a - 4bV\right)dVδQ=(25​a−4bV)dV, смена знака при V∗=5a8bV^* = \dfrac{5a}{8b}V∗=8b5a​. Эта точка правее точки максимума температуры V=a2bV = \dfrac{a}{2b}V=2ba​: после максимума TTT газ ещё какое-то время получает теплоту.

Приём 3. Колебания поршня: метод Рюхардта

Поршень массой mmm и площадью SSS закрывает сосуд объёмом VVV с газом при давлении ppp. При малом сдвиге xxx газ сжимается адиабатно (колебания быстрые): Δp=−γpSxV\Delta p = -\gamma p\dfrac{Sx}{V}Δp=−γpVSx​. Возвращающая сила F=ΔpS=−γpS2VxF = \Delta pS = -\dfrac{\gamma pS^2}{V}xF=ΔpS=−VγpS2​x — как у пружины (Уравнение колебаний):

ω2=γpS2mV.\omega^2 = \frac{\gamma pS^2}{mV}.ω2=mVγpS2​.

Измерив период, находят γ\gammaγ — так в 1929 году Рюхардт определял показатель адиабаты.

Приём 4. Наибольшая работа и энтропия

Двигатель работает между двумя конечными телами, и их температуры сближаются. Наибольшая работа — у обратимого двигателя, для которого суммарная энтропия не меняется. Для двух одинаковых тел теплоёмкостью CCC:

Cln⁡TT1+Cln⁡TT2=0⇒T=T1T2,Amax⁡=C(T1+T2−2T).C\ln\frac{T}{T_1} + C\ln\frac{T}{T_2} = 0 \quad\Rightarrow\quad T = \sqrt{T_1T_2}, \qquad A_{\max} = C(T_1 + T_2 - 2T).ClnT1​T​+ClnT2​T​=0⇒T=T1​T2​​,Amax​=C(T1​+T2​−2T).

Если просто привести тела в контакт, получится T=T1+T22T = \dfrac{T_1 + T_2}{2}T=2T1​+T2​​ — выше, чем T1T2\sqrt{T_1T_2}T1​T2​​. Эта разница энергии и есть упущенная работа.

Приём 5. Стационарные потоки и излучение

В стационарном режиме поток теплоты через каждое звено цепи одинаков. Это работает и для слоёв стены, и для экранов при излучении. Тонкий чёрный экран между пластинами с температурами T1T_1T1​ и T2T_2T2​ принимает температуру T4=T14+T242T^4 = \dfrac{T_1^4 + T_2^4}{2}T4=2T14​+T24​​ и уменьшает поток вдвое. NNN экранов уменьшают поток в N+1N + 1N+1 раз — так устроена экранно-вакуумная теплоизоляция спутников.

Интерактив

Открыть на весь экран ↗
  1. Меняй показатель политропы nnn. При каких nnn газ при расширении получает теплоту, а при каких отдаёт?
  2. Найди процесс, в котором газ при расширении получает теплоту, но остывает.
  3. Сравни политропу с изотермой и адиабатой. Между какими линиями лежат процессы с отрицательной теплоёмкостью?

Типичные ошибки

  • В КПД берут теплоту всего участка. Если на участке знак δQ\delta QδQ меняется, берут только полученную часть.
  • Колебания поршня считают изотермическими. Колебания быстрые — сжатие адиабатное, в формуле стоит γ\gammaγ.
  • Наибольшая работа между телами — по КПД Карно с начальными температурами. Температуры меняются, нужен баланс энтропии.
  • Отрицательная теплоёмкость невозможна. Возможна: газ получает теплоту и остывает, если совершает большую работу.

Пример 1. Давление пропорционально объёму

Условие. Одноатомный идеальный газ расширяется так, что его давление пропорционально объёму: p=αVp = \alpha Vp=αV. Найди молярную теплоёмкость газа в этом процессе.

Дано: p=αVp = \alpha Vp=αV, CV=32RC_V = \dfrac32RCV​=23​R. Найти: CCC.

Анализ. C=CV+p dVν dTC = C_V + \dfrac{p\,dV}{\nu\,dT}C=CV​+νdTpdV​. Связь dVdVdV и dTdTdT найдём, подставив процесс в уравнение состояния.

Решение.

  1. pV=αV2=νRTpV = \alpha V^2 = \nu RTpV=αV2=νRT, дифференцируем: 2αV dV=νR dT2\alpha V\,dV = \nu R\,dT2αVdV=νRdT.
  2. p dV=αV dV=νR dT2p\,dV = \alpha V\,dV = \dfrac{\nu R\,dT}{2}pdV=αVdV=2νRdT​.
  3. C=32R+R2=2R≈16,6C = \dfrac32R + \dfrac R2 = 2R \approx 16{,}6C=23​R+2R​=2R≈16,6 Дж/(моль·К).

Проверка. Это политропа pV−1=constpV^{-1} = \text{const}pV−1=const, n=−1n = -1n=−1: C=CV−Rn−1=32R+R2=2RC = C_V - \dfrac{R}{n - 1} = \dfrac32R + \dfrac R2 = 2RC=CV​−n−1R​=23​R+2R​=2R. Совпадает. Теплоёмкость больше CVC_VCV​ и CpC_pCp​, потому что давление растёт и газ совершает большую работу.

Ответ: 2R≈16,62R \approx 16{,}62R≈16,6 Дж/(моль·К).

Что запомнить. Теплоёмкость процесса: C=CV+p dVν dTC = C_V + \dfrac{p\,dV}{\nu\,dT}C=CV​+νdTpdV​; связь dVdVdV и dTdTdT — из уравнения процесса и уравнения состояния.
