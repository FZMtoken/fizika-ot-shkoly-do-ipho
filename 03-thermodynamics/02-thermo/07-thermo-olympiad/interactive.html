Политропы: pVⁿ = const

1 моль гелия расширяется из состояния 1 (10 л, 200 кПа) по политропе pVⁿ = const. Пунктиром — изотерма (n = 1) и адиабата (n = 5/3) через ту же точку. Цвет процесса: красный — газ получает теплоту, синий — отдаёт. Справа — столбики Q = ΔU + A′.

Попробуй сам:
  1. Поставь n = 0 и n = 1. Какие это процессы? Чему равна теплоёмкость?
  2. Найди n, при котором газ при расширении получает теплоту, но остывает. Между какими пунктирными линиями лежит такая политропа?
  3. Поставь n = 1,4 и проверь задачу о теплоёмкости −R.
